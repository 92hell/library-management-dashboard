# Test catalogue

Generated by `scripts/generate-test-catalog.py` from the test names - do not edit by hand.
Each line is one test; together they are the specification of the system's behaviour.

Run everything: `mvn clean verify` (backend; add `-Pmariadb` to run it on MariaDB in Docker),
`cd frontend && npm test` (frontend), and after `mvn -Pfullstack package` also
`cd e2e && npm test` (end-to-end, in a real browser).

Totals: 215 backend test methods (parameterised ones run once per case), 137 frontend tests, 10 end-to-end journeys.
